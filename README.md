## Direction

기획부터 배포까지 전 과정을 AI와 함께 혼자 완수하는 구조를 만드는 것이 목표입니다.  
AI를 도구로 쓰는 게 아니라, 각자 역할을 가진 비서들이 일하고 내가 의사결정과 검수를 맡는 방식 — 1인 프로덕트지만 팀처럼 움직이는 개발 구조를 지향합니다.  
그 위에서 추천·통계·챗봇 같은 AI 기능을 서비스 안에 직접 녹여내는 것도 관심 영역입니다.
